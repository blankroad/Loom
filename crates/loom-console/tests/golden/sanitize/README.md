# Render sanitizer golden corpus

Shared by the Rust `loom_console::sanitize` module and any TypeScript port (UART plan
§5.4: "TS 포팅 + 골든 코퍼스 동치 시험"). Both implementations must produce the same
bytes for every case.

## Format

- `<name>.in` — raw device bytes (binary, no trailing newline).
- `<name>.out` — expected sanitizer output for the whole `.in` fed at once (binary).
- The output must be identical when `.in` is fed one byte at a time or split anywhere.
- The prefix selects the configuration:
  - `web_…` → `SanitizeConfig::web()` (profile Web, mouse off).
  - `tui24_…` → `SanitizeConfig::tui(24)` (profile Tui, 24 rows, mouse off).
- Expected outputs were written by hand from the rules below, not generated by the code.

## Rules the cases cover

| Case | Rule |
|---|---|
| `web_query_*`, `web_window_ops` | Terminal queries and window reports are removed (DA1/DA2/DA3, XTVERSION, DSR/CPR, DECRQM, DECREQTPARM, `CSI … t`, kitty `CSI ? u`) |
| `web_dcs_*`, `web_apc_pm_sos` | DCS / SOS / PM / APC strings are removed |
| `web_osc_*`, `web_osc8_link`, `web_osc52` | Every OSC is removed; OSC 8 link text stays; a string ends at BEL, ST, CAN/SUB or the next ESC |
| `web_osc_10k` | A 10 KiB OSC is discarded without buffering; text after its terminator passes |
| `web_mouse_focus`, `web_mixed_decset` | Mouse and focus modes are removed; a mixed DECSET keeps only allowed modes |
| `web_sgr_cursor_pass`, `web_alt_screen`, `web_bracketed_paste`, `web_charset_line_drawing` | SGR, cursor motion/erase, DECSC/DECRC, cursor style, alternate screen, bracketed paste and G0 charsets pass verbatim |
| `web_ris`, `web_enq_nul_del`, `web_can_abort` | RIS, C0 controls outside BEL/BS/HT/LF/CR, DEL are removed; CAN aborts a sequence |
| `web_c1_csi_codepoint`, `web_raw_8bit_csi`, `web_utf8_truncated` | C1 code points are removed; invalid UTF-8 (incl. a raw 0x9B) becomes U+FFFD |
| `web_csi_len_4095/4096/4097` | Sequence length cap: ≤ 4096 bytes pass, 4097 is discarded (`overlong`) |
| `tui24_decstbm` | TUI clamps the DECSTBM bottom margin to `rows − 1` |
