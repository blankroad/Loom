7. Backend 계약과 CLI 초안 (소형 Luna용) — 제안, 미구현

trait DebugBackend {
  fn capabilities(&self) -> Caps;   // nonintrusive_read, realtime_mode, flash, trace, multi_core
  fn open(spec) / close(leave_as_is)
  fn run_state() -> {state, observed_at, certainty: fresh|stale|unknown}
  fn read(loc, n, allow_halt) -> Result<Vals, E_WOULD_HALT>
  fn halt() / run() / step(kind) / bp(op) / reset(kind) / load(img)   // action, write_state
}
loom dbg status <t>
loom dbg open <t> --ccxml F --core RE
loom dbg read <t> <sym|0xADDR> [--allow-halt]
loom dbg watch <t> --expr 'g_state==3' --every 20ms --timeout 5s   → {matched,value,t_match,polls,gaps,lat_p50,lat_p95}
loom dbg sample <t> --vars a,b --every 10ms --for 2s --summary min,max,last
loom dbg halt|run|step <t>   ·   loom dbg reset|load|flash <t> (향후, 명시 요청 action)   ·   loom dbg close <t>
  • Polling과 판정은 host worker가 수행하고, 에이전트에는 키 고정 JSON 한 줄만 반환합니다. 원본 DSS 덤프는 반환하지 않습니다.
  • STOP: 큐와 watch를 취소합니다. halt·resume·reset·flash·disconnect는 하지 않습니다. 링크가 끊기면 certainty=stale와 증가하는 age_ms를 보고합니다.
  • 지연 지표: 획득 지연(host↔bridge↔probe), LLM 지연, end-to-end(요청→실제 시작, 이벤트→올바른 보고)를 모두 기록합니다. 원인을 찾을 수 있게 구간을 나누되, end-to-end 값을 판정에서 빼지 않습니다.
  • 재연결은 사용자가 명시적으로 open할 때만 합니다(Reopen::None). 자동 halt나 reset은 하지 않습니다.
