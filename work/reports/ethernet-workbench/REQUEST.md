## Required working interactions
1. **Multiple interfaces/channels** with alias, iface/IP/link state, per-channel capture state/counts. Initially two simulated channels; add/select/start/stop a channel independently. Show only actual open channels. Stopping one leaves others live and retains history. Clearly SIM, no pretend NIC discovery.
2. **Capture workspace**: dense packet table (time/channel/source/destination/protocol/length/info), selection, keyboard up/down, enough realistic Ethernet/IPv4/UDP/TCP/ARP plus DoIP/SOMEIP-labelled deterministic fixture traffic. Selected packet details expandable tree and actual byte/ASCII pane with field↔byte highlighting matching raw data. Packet data/length/hex coherent, no fake random numbers inconsistent with decoded tree. Resizable list/detail/bytes boundaries via actual pointer drag. Initial 1440 desktop highest priority, 768/390 controls reachable without clipped destructive controls.
3. **Filters**: visible capture vs display distinction; display filter supports a documented small valid subset plus invalid-state validation that retains prior results; useful suggestions/examples/clear. Filter applies to correct channel(s), count shows displayed/captured. Pause display distinct from capture Stop; live data continues while view paused, resume catches up. Bounded retention/drop notice, no unlimited log growth.
4. **Socket testing**: dedicated TCP/UDP test tab/drawer/panel (not always overwhelming capture workspace). Explicit target channel/endpoint and simulated connection state; send HEX or text, input validation, RX/TX timestamped transcript, save/edit/run named packet templates. Send is local simulator only, produces traceable TX and deterministic RX on that channel; never a real OS socket/network request. Disconnect blocks send, per-channel independent. Do not implement full UDS workflows; Ethernet DoIP inspection is protocol layering only.
5. **Follow stream** or useful selected-conversation view with directional payload, and actual export of local displayed packet rows or PCAP if correctly implemented. Honest format naming, no fake file status. Settings/template persistence under own localStorage prefix; reload must not silently restart sending or automation.
