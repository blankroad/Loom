# UART workbench mockups

Bench Light 안에 임베딩한 UART 사용자 작업대의 Sol·Opus 비교 목업이다. 실제 UART 백엔드나 장비에 연결하지 않으며 로컬 장치 시뮬레이터로 동작한다.

## 실행

저장소 루트에서 아래 명령을 실행하고 `http://127.0.0.1:4180/uart-workbench/`를 연다. 이미 해당 포트에서 프리뷰가 실행 중이면 기존 서버를 사용한다.

```sh
python3 -m http.server 4180 --bind 127.0.0.1 --directory work/reports
```

- `index.html`: 두 안 비교 진입점.
- `opus/index.html`: 최신 REV6.1. 실제 xterm.js, 자유 분할·크기 조절·탭 이동, 저장 세션·포트 선택, 매크로 CRUD 및 즉시 실행, 매크로 실행 범위 `활성 / 연결된 모두 / 선택`, 일반 키 입력 브로드캐스트와 독립적인 대상 선택, 타임스탬프와 실시간 기록 옵션.
- `sol/index.html`: 앞서 브라우저 검증한 독립 비교안. 최신 Opus 변경은 이 안에 적용하지 않았다.
- `*/SURVEY.md`: 공식 도구 벤치마킹과 채택 근거.
- `*/HANDOFF.md`, `RUN.md`, `qa/`: 소스 식별자, 검사 결과, 변경·인계와 브라우저 증거.
- `opus/vendor/xterm/`: MIT 라이선스의 @xterm/xterm 6.0.0 로컬 배포본과 라이선스·출처.

## 최신 검증 상태

Opus REV6.1의 일반 기능 검사 122개는 마지막 미해결 고정 대상 전체 차단 수정 전에 통과했다. 그 최종 수정은 별도의 영향 범위 회귀 검사 3개가 통과했다. 모두 jsdom 검사이며 브라우저 검증으로 간주하지 않는다. 독립 Opus 정적 리뷰에서 가져오기 대상 매핑 결함 F5의 해결을 확인했다.

Opus의 최종 브라우저·실제 파일 기록 검증은 **대기 중**이다. Ego Lite TaskSpace 15가 사용자 제어 상태여서 제어권 반환 후 재개한다. `qa/QA-HANDOFF.md`와 `qa/opus/STATUS.md`에 남은 검사가 있다. 과거 스크린샷과 브라우저 결과는 각각 당시 소스에 대한 증거이며 최신 REV6.1의 통과 증거가 아니다. Sol 비교안은 해당 소스에 대해 브라우저 검사 50개를 통과했다.

자체 검사 스크립트는 작성 당시 작업 경로와 기존 `ui/node_modules/jsdom`에 의존하는 개발 증거다. 목업 실행에는 Node 의존성 설치가 필요하지 않다.
