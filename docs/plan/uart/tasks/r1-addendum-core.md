# R1 긴급 추가 지시 — 진행 중인 R1 초안에 즉시 반영 (두 워커 공통)

사용자 재지시로 docs/plan/02-core-principle.md 가 추가되었다. 00-brief.md, uart/brief.md 보다 우선한다. 지금 읽어라.

해야 할 일:
1. 02-core-principle.md 전체를 읽는다.
2. 작성 중인 R1 초안(r1-opus.md 또는 r1-sol.md)을 그 체크리스트 6개 항목 기준으로 점검·보완한다:
   - 맨 앞에 "## 0. 핵심 루프" 절: UART에서 직접 접근/읽기/쓰기/사용자 실시간 표시 4요소가 각각 무엇으로 구현되는지 한 표.
   - 종단 간 시나리오 1개 이상: 에이전트가 send → 장치 응답 → 사용자 attach 화면에 몇 ms 안에 표시(출처 강조 포함) → 사용자가 타이핑/Ctrl-C 등으로 개입. 구체 명령과 ASCII 화면으로.
   - 실시간성 목표치: 장치 rx → 사용자 화면 지연 목표(UART < 100 ms 기준 제안), 고속 로그 폭주(예: 921600 baud 연속 출력)에서도 화면이 멈추거나 거짓말하지 않는 방법(드롭/백프레셔 표시, 렌더 스로틀 명시, 원시 기록은 손실 없음 등).
   - M1 = 걷는 뼈대: 시뮬레이션(pty 가짜 디바이스) 위에서 4요소가 최소 형태로 모두 동작. 부가 기능은 M1 이후로.
   - 사용자 화면이 에이전트 세션과 분리되지 않음: 에이전트가 쓰는 중 사용자가 attach 하면 즉시 같은 스트림(직전 스크롤백 포함). 에이전트 전용 숨은 연결 금지 — 데몬을 거치지 않는 직접 포트 열기 경로가 없음을 명시.
   - 이 원칙에 기여하지 않는 기능(예: XMODEM, 웹 뷰, 고급 hex 편집 등)은 "후순위" 또는 "비범위"로 명시.
3. 초안 끝에 "## 핵심 원칙 자체 점검" 절을 붙여 6개 항목 각각 충족 여부와 해당 절 위치를 적는다.
4. 그 다음 원래 R1 지시를 계속 마친다. 완료 시 "R1 DONE: <파일경로>" 한 줄.
