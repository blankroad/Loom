# R4 보조 점검 — uart-opus (내부 일관성)

리드가 docs/plan/uart/plan.md (통합본 v1)를 썼다. 수정하지 말고 점검만 해서 docs/plan/uart/r4-consistency-opus.md 에 써라. 15분 내외.

1. **내부 모순**: 절 사이에서 서로 다른 값/규칙(예: 기본값, 마일스톤 배정(M1/M2/M3), 종료 코드, 키 바인딩의 M 표시, 타임아웃, 상한 수치, 상태 이름, 동사·옵션 이름)을 찾아 표로(위치 A / 위치 B / 어느 쪽이 맞는지 추천).
2. **마일스톤 의존성 오류**: M_n 수용 기준이 M_n+1 이후 작업에 의존하는 경우, §12 작업 표의 의존성 누락/순환.
3. **에이전트 사용성 점검**: SKILL.md 초안과 §4 CLI 명세가 어긋나는 곳(SKILL이 존재하지 않는 옵션을 쓰거나, M1에 없는 기능을 M1 스킬 v0에서 안내하는 등).
4. **사용자 UX 점검**: §5 뷰어 규칙이 §3.7 입력 규칙·§10 승인 흐름과 맞물리는지(예: 승인 팝업 중 키 입력, 전체화면 모드에서 hold/팝업).
5. 맨 끝에 "리드가 반영할 수정 목록"(필수/권장)을 번호로.
