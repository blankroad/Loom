## 당신의 관점 (무게를 둘 것)
- 아키텍처: 데몬/클라이언트 구성, 세션·포트·커서 모델, IPC 메시지 형태, 상태 머신(포트 열림/끊김/재연결).
- 사용자/에이전트 UX: 에이전트가 쓰기 쉬운 CLI 동사 설계(일관성, 비대화형, --json 스키마), 사용자 TUI 화면 구성과 키 바인딩, 입력 혼재 규칙의 UX(사용자가 무엇을 보게 되는지).
- 스킬 설계: SKILL.md 본문 초안(짧게)과 references 파일 목록·내용 개요, 에이전트가 흔히 하는 작업 레시피(부팅 대기→로그인→명령→결과 파싱, 리셋 후 부트로그 캡처 등).
- 안전 규칙: 위험 등급 표, 확인 흐름, 사용자 개입(사용자가 타이핑 중이면 에이전트는?) 정책.
- 다른 절(라이브러리, 시뮬레이션 등)도 빠짐없이 쓰되, 위 영역을 특히 깊게.
