## 반드시 다룰 것
1. **TC 형식**
   - 자연어 자유 서술부터 반구조 표까지 받는다. 반구조 표의 항목은 전제·장비·환경·단계·기대 결과·합격 기준이다.
   - 정본 파일 형식을 하나 고른다(예: Markdown 표 + 머리말 YAML). 사람이 쓰기 쉬운 것이 우선이다.
   - 사내 엑셀·문서 TC 가져오기 경로를 제시한다.
   - 에이전트가 자연어 TC를 실행 가능한 단계로 해석한 결과를 **실행 전에 사람에게 보여 주고 확인받는 흐름**(해석 계획 = plan)을 둔다.
2. **테스트 세션 CLI**
   - 명령: `loom test start/plan/step/verdict/evidence/note/end/report/freeze` 등.
   - D5 봉투·종료 코드를 지키고, 출력 예를 함께 쓴다.
   - 세션 시작 시 **일괄 사전 승인**(R2/R3 범위 묶음, R4는 제외 또는 단계별)을 둔다.
   - 단계 마커가 모든 도메인 타임라인에 찍히게 한다.
   - CORE와 나눌 경계를 명시한다. 코어 = 세션·단계·증거 검증 엔진·저장. TEST = 형식·스킬·판정 규칙·보고서.
3. **증거 기반 판정(환각 방지)**
   - 증거 참조 형식: 이벤트 `seq` 범위, 신호 값과 시각, UDS 응답 바이트, UART 텍스트 매치, LA 디코드 행, DLT 메시지 등.
   - Loom 검증기가 확인할 것: 증거가 존재하는가, 세션·단계 시간 창 안인가, 기대 조건(술어)과 일치하는가.
   - 에이전트가 주장만 하고 증거가 없으면 PASS를 금지한다.
   - 판정 값: `pass|fail|inconclusive|blocked|skipped`. 사람 판정(override)은 origin=user로 기록한다.
   - 술어 표현 방식의 후보를 고르고 이유를 쓴다(예: 단순 비교 DSL vs CEL vs JSONPath). 사실 확인은 Sol이 한다.
4. **실패와 개입**
   - 실패 시 행동: 다음 단계 진행 / 중단 / STOP / finally(A15) / 복구 송신.
   - 사용자가 UI에서 개입하는 경우: 단계 건너뛰기, 재시도, 판정 수정, 일시정지.
   - 에이전트가 사람에게 물어야 하는 조건을 정한다.
5. **보고서**: HTML(UI에서 열람, 기록 구간 링크) + JUnit XML. 증거 링크와 재현 정보(장비·펌웨어 버전·프로파일 해시)를 넣는다.
6. **회귀 재실행**
   - 에이전트 실행 기록을 결정적 시나리오(`loom run`, D12)로 고정하는 `freeze`를 둔다.
   - 무엇이 결정적으로 고정되고 무엇이 안 되는지 쓴다(자연어 판단, 타이밍).
   - 러너와 테스트 세션의 관계를 정한다(같은 엔진인가?).
7. **`loom-test` 스킬 초안**
   - SKILL.md 본문 60줄 이하.
   - 내용: TC 해석 규칙, 실행·대기·판정·보고 규칙, 증거 인용 의무, 실패 시 행동, 사람에게 묻는 조건, 우회 금지.
   - 공통 `loom` 스킬과 도메인 스킬은 참조만 한다.
8. **UI 테스트 실행 화면**
   - 담을 것: 현재 단계, 실시간 증거, 판정, 사람 개입 버튼, 일괄 승인 상태.
   - ASCII 와이어프레임과 패널 명세를 쓴다. 각 요소에 무엇을, 어떤 지연으로 보이는지, 사용자 입력을 적는다.
   - 이 부분은 나중에 `_xteam/ui-test.md`로 옮긴다.
9. **예시 TC 3개 이상**
   - 모듈을 섞는다. 예: UART 부팅 로그 + CAN 신호 + UDS DTC 읽기·삭제. DLT 레벨 + LA로 UART 물리 확인. PSU(sim) 전원 사이클 + 부팅 시간.
   - 각각 자연어 원문 → 해석 계획 → 단계별 명령 → 증거 → 판정 예시를 쓴다.
   - 이 중 하나는 **시뮬레이션 위 E2E 시나리오**(M1 수용)로 쓴다.
10. **마일스톤과 작업 분해**
    - M0–M3과 수용 기준을 쓴다. M1 = 시뮬레이션 위 혼합 TC 1개를 웹 UI로 실행하고, 사용자 개입과 증거 검증을 함께 시연한다.
    - 작업 분해에는 담당(Opus/Sol)과 의존성을 표시한다.
