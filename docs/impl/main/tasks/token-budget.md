# P1까지 토큰 사용 운영 규칙 — 메인, 2026-11-11

- 근거: docs/impl/main/reports/token-audit-2026-11-11.md.
- 새 작업 전 현재 main의 의존성이 준비됐는지 먼저 확인한다. 아직 없으면 준비 결과를 보존하고 차단을 기록한다. 같은 실패를 반복 호출하지 않는다.
- 감시는 메인 2분 셸에 모은다. 리드·워커가 모델 호출로 서로를 상시 감시하지 않는다. 변한 SHA·MERGE READY·새 BLOCKED 등 신호만 통보한다.
- 워커 검증은 소유 crate의 필요한 범위로 제한한다. main은 인계 §4의 병합 후 전체 검사를 유지한다. 같은 SHA·같은 구성의 성공 검사는 반복하지 않는다.
- P1 전 P2/P3 선행·추가 자식 에이전트 생성은 보류한다. 독립 작업이 없으면 워커는 대기한다.
- 보고는 변경 파일·핵심 결정·검사 명령/결과·차단만 짧게 남긴다. 파일 전체·긴 터미널 로그를 반복해 문맥에 넣지 않는다.
- 세션 정리·모델 변경은 현재 코드와 인수 상태를 보존한 뒤 별도 결정한다. 자동 모델 전환이나 영구 설정 변경은 하지 않는다.
